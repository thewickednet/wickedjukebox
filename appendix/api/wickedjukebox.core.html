wickedjukebox.core.smartfind module¶

This module contains an entry point to run a “smart” query to find the next best song taking channel statistics into account.

wickedjukebox.core.smartfind.LAST_PLAYED_CUTOFF = 604800¶

A song gains the maximum “last-played” score boost after this many seconds

class wickedjukebox.core.smartfind.ScoringConfig(*values)¶

Bases: Enum

Possible configuration values to influence the scoring query

CANDIDATE_POOL_SIZE = 'candidate_pool_size'¶

0 (or absent) = disabled (score the whole table). >0 = score only a random pool of this many candidate ids (fast, flat with library size).

wickedjukebox.core.smartfind.get_standing_query(session, standing: str, setting_name: str, proofoflife_timeout: int) → Query[Any]¶

Return a query retrieving the number of users that either “hate” or “love” a given song. Only users that have been listening within the last proofoflife_timeout seconds will be taken into account.

wickedjukebox.core.smartfind.smart_random_no_users(session, never_played: int, last_played: int, randomness: float, max_random_duration: int)¶

Fetch a random song without taking any user-statistics into account. Only consider channel statistics.

Parameters:

  • never_played – A score bonus for songs that have never been played.

  • last_played – The maximum recency penalty applied to a just-played song, decaying linearly to 0 by LAST_PLAYED_CUTOFF (never-played songs incur no penalty).

Randomness:

A score modifier adding a dash of randomness to the overall score.

Max_random_duration:

Don’t return songs with a longer duration than this value (in seconds).

wickedjukebox.core.smartfind.smart_random_with_users(session, never_played: int, user_rating: int, last_played: int, proofoflife_timeout: int, randomness: float, max_random_duration: int, num_active_users: int) → Query[Tuple[int, str, float]]¶

Like smart_random_no_users(), but also factors in the ratings of currently-listening users: songs “loved” by active users get a score boost (loves / num_active_users * user_rating) and songs “hated” by any active user are filtered out. The base score is the same recency penalty + never-played bonus + randomness as the no-users variant.
