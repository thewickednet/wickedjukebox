# Rebase daemon alembic/models onto Django — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the daemon's alembic-built dev/test schema a functionally faithful mirror of djukebox's authoritative Django schema, by reconciling the SQLAlchemy model indexes and squashing the 5-migration chain into one clean baseline.

**Architecture:** Two coupled changes: (1) edit the `__table_args__` index declarations on the in-scope daemon tables to match Django's index set (drop low-value/phantom indexes, add the `(available, broken)` composite), keeping the daemon-required UNIQUE constraints Django under-declares; (2) replace the 5 alembic migrations with a single autogenerated baseline that builds the reconciled `Base.metadata`. Schema-only — no query/behavior changes.

**Tech Stack:** Python 3.10, SQLAlchemy < 2.0 (declarative), Alembic, MariaDB 10 (ephemeral Docker container), pytest.

## Global Constraints

- **SQLAlchemy pinned `< 2.0`** — use 1.4-style `Index(...)` / `ForeignKeyConstraint(...)` in `__table_args__`; do not use 2.0 APIs.
- **Alembic is dev/test-only** — never run against production. This change only affects the daemon's throwaway DBs.
- **Formatting:** black + isort, **line-length 80**, isort black profile. CI pins **black 23.3.0** and **isort 5.12.0** — format with those exact versions or you will churn already-formatted lines (the repo venv's newer black/isort reformat differently).
- **Scope is index/constraint declarations only.** Do NOT change column types, nullability, PKs, or any query/behavior. Do NOT touch Tier 3 tables (`tag`, `song_has_genre`, `song_has_tag`, `user_song_stats`, `user_album_stats`, `channel_album_data`, `collection_has_song`, `playlist`, `playlist_has_song`) or vestigial infra tables (`auth_*`, `django_*`, `render_presets`, `shoutbox`, `thumbnail_kvstore`, `rest_framework_tracking_*`).
- **Daemon-side keep-list (must remain in the schema):** `song.UNIQUE(localpath)`, `artist.UNIQUE(name)`, `album.UNIQUE(path)`, and AUTO_INCREMENT integer PKs. Django under-declares these; the daemon needs them.
- **Spec:** `docs/superpowers/specs/2026-07-12-alembic-rebase-on-django-design.md`.

```python
# pylint: skip-file
"""Assert the daemon's built schema matches the django-reconciled index set.

Introspects the live (alembic-built) schema via SQLAlchemy. Guards against
re-drift: the daemon-required uniques Django under-declares are asserted KEPT,
and the phantom/low-value indexes are asserted GONE.
"""

from sqlalchemy import inspect


def _index_names(insp, table):
    names = {ix["name"] for ix in insp.get_indexes(table)}
    names |= {uc["name"] for uc in insp.get_unique_constraints(table)}
    return names


def _index_colsets(insp, table):
    return {tuple(ix["column_names"]) for ix in insp.get_indexes(table)}


def _unique_colsets(insp, table):
    sets = {
        tuple(ix["column_names"])
        for ix in insp.get_indexes(table)
        if ix.get("unique")
    }
    sets |= {
        tuple(uc["column_names"])
        for uc in insp.get_unique_constraints(table)
    }
    return sets


def test_song_indexes_reconciled(dbsession):
    insp = inspect(dbsession.get_bind())
    names = _index_names(insp, "song")
    # ADDED composite, KEPT mood index
    assert ("available", "broken") in _index_colsets(insp, "song")
    assert "song_mood_score_idx" in names
    # DROPPED low-value single-column indexes
    assert "broken" not in names
    assert "title" not in names
    assert "exclude_from_random" not in names
    # KEPT daemon-required unique Django under-declares
    assert ("localpath",) in _unique_colsets(insp, "song")


def test_album_indexes_reconciled(dbsession):
    insp = inspect(dbsession.get_bind())
    names = _index_names(insp, "album")
    assert "name" not in names
    assert "type" not in names
    assert ("path",) in _unique_colsets(insp, "album")


def test_channel_song_data_indexes_reconciled(dbsession):
    insp = inspect(dbsession.get_bind())
    # redundant single channel_id gone; composite (channel_id, song_id) kept
    assert ("channel_id",) not in _index_colsets(insp, "channel_song_data")
    assert ("channel_id", "song_id") in _unique_colsets(
        insp, "channel_song_data"
    )


def test_queue_and_setting_indexes_reconciled(dbsession):
    insp = inspect(dbsession.get_bind())
    assert ("position",) not in _index_colsets(insp, "queue")
    # single var gone; (var, channel_id, user_id) composite unique kept
    assert ("var",) not in _index_colsets(insp, "setting")
    assert ("var", "channel_id", "user_id") in _unique_colsets(insp, "setting")
```
